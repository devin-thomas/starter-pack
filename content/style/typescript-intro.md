## Why use TypeScript?

TypeScript is a strong fit when a JavaScript project has enough moving parts that explicit contracts and compiler feedback start paying for themselves. It is especially useful in web apps, React and React Native projects, Node.js services, CLIs, agent tooling, and codebases where several people or agents may touch the same data and APIs.

The value is not that every program needs more syntax. The value is that important assumptions become visible in source and checkable before the code runs. For a tiny one-off script or experiment where that structure would add more friction than protection, plain JavaScript can still be enough.
