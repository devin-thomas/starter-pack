## Why use this React + TypeScript guide?

React is a UI framework; this guide applies Devin’s TypeScript ownership and contract rules to components, hooks, effects, browser boundaries, and an optional Next.js profile.

## What is settled and what is not

React + TypeScript 1.0.0 is the stable house guide. All 33 rules are finished and approved, including the React hook-binding exception in RX006. Agents may read and apply the complete guide alongside TypeScript 1.0.0 without further style approval. Keep framework, dependency, and deployment choices specific to the project.

## How to apply it

Use the stable TypeScript, Godot, and Kotlin guides as established precedent where relevant, then apply this guide to React and its scoped Next.js profile. Keep project-specific versions, dependencies, product behavior, and deployment decisions in the target repository.
