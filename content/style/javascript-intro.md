## Why use this JavaScript guide?

JavaScript remains executable source while JSDoc and static checking make contracts visible; this guide defines when that tradeoff is appropriate and how to keep it safe.

## What is settled and what is not

This page is intentionally public while the guide is still being reviewed. Established house principles are translated into this ecosystem, but any section marked as an owner choice remains unresolved unless it explicitly says accepted. The status badge and raw Markdown preserve that distinction for both people and coding agents.

## How to apply it

Use the stable TypeScript, Godot, and Kotlin guides as established precedent where relevant, then use this draft only for the ecosystem-specific rules it actually states. Keep project-specific versions, dependencies, product behavior, and deployment decisions in the target repository. Publishing the draft is not permission to migrate existing code.
