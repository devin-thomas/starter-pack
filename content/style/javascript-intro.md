## Why use this JavaScript guide?

JavaScript remains executable source while JSDoc and static checking make contracts visible; this guide defines when that tradeoff is appropriate and how to keep it safe.

## Accepted house guide

JavaScript 1.0.0 is the stable house guide. All 28 rules are finished and approved.

## How to apply it

Apply this guide within its stated language and ecosystem scope. Use the companion house guides where relevant, and keep project-specific versions, dependencies, product behavior, and deployment decisions in the target repository.
