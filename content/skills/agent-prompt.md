# Agent Prompt

Build recognizable agent handoffs with short prompts and useful copy.

## Use this when

Add a copyable task prompt, an agent picker, a verified draft link, or a project continuation handoff to a site.

## How it works

The agent uses authentic product marks and readable names, keeps the prompt near 40 words and 300 characters, and puts detailed instructions in a retrievable guide. It checks that preview, clipboard, and launch text agree and provides manual recovery if copying fails.

The component follows your project's existing visual conventions. Your explicit direction takes precedence. If neither exists, the skill includes an optional neutral light/dark treatment and scoped stylesheet. It does not require private skills or accounts.
