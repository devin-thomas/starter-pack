# Branded Sign-In

Build recognizable authentication interfaces with authentic provider artwork and verified interactions.

## Use this when

Create or review sign-in, registration, account linking, recovery, or provider-choice screens. Backend-only authentication changes do not require this presentation workflow.

## How it works

The agent checks the product identity, supported authentication methods, existing assets, and actual provider requirements. It uses authentic provider and method marks with visible names, preserves original logo geometry, and matches the product's visual language.

The review covers success, cancellation, errors, loading, focus, keyboard use, narrow screens, and theme changes. Appearance checks are separate from proving a successful authenticated session.
