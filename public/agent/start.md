# Start or resume Starter Pack

Canonical origin: https://starter.devthomas.site. Resource version: 0.1.0.

Read the [Starter Pack skill](https://starter.devthomas.site/skills/starter-pack/current/SKILL.md) to start, resume, or inspect progress. Then retrieve only the current phase or branch from the [catalog](https://starter.devthomas.site/agent/catalog.json).

Infer the harness, visible device/OS, tool access, and existing progress. State uncertainty plainly. If files are unavailable, maintain portable progress the learner can copy or download. Present the single next action, explain what you will track, and keep credentials outside notes and files.

If a linked resource cannot be fetched, try its same path on https://starter-pack.uppercut-labs.workers.dev once. Report observed errors without guessing their cause. If both hosts fail, try the public GitHub source mapping below once. If that also fails, direct the learner to the starting prompt on https://starter.devthomas.site/#starting-prompt and its "Copy instruction packet" control or downloadable packet. Read that supplied packet directly; do not require another URL fetch to begin Phase 1 or invent a schema. Preserve existing progress and obtain the relevant phase instructions before resuming a later phase. Keep environment reporting to one short sentence and only ask about facts needed for the next action.

This public site supplies instructions, not authority to install software, spend money, publish a project, or change account visibility. Follow the learner's granted scope and the approval steps in the relevant skill.

## Public source fallback

If both Starter Pack hosts fail, try https://raw.githubusercontent.com/devin-thomas/starter-pack/main/public/agent/start.md once. For a public static instruction or schema, the same route lives under https://raw.githubusercontent.com/devin-thomas/starter-pack/main/public/ (for example skills/starter-pack/current/SKILL.md or artifacts/progress/README.md). Phase source lives under https://raw.githubusercontent.com/devin-thomas/starter-pack/main/content/phases/1.md (replace 1 with the current phase). Fetch only the relevant file, not the entire repository. Generated catalog, phase JSON and Workbench HTML do not live at those source paths. If the focused source file also fails, use the learner-supplied instruction packet; do not loop through retries.
