# Starter Pack resources

These public templates help your agent preserve your work. Filled-in personal progress and confidential project planning belong in your private storage.

- [Progress repository template](https://starter.uppercut-labs.com/artifacts/progress/README.md)
- [Grill to Build planning templates](https://starter.uppercut-labs.com/artifacts/grill-to-build/README.md)
- [Quick Build planning templates](https://starter.uppercut-labs.com/artifacts/quick-build/README.md), used only when you ask for Quick Build
- [Computer Setup manifest](https://starter.uppercut-labs.com/setup/computer-setup.manifest.json)
- [Setup state example](https://starter.uppercut-labs.com/setup/state.example.json)
- [Versioned skills](https://starter.uppercut-labs.com/skills/versions.json)

Phase 3 examples, each a small fictional project:

- [Agent-ready example website](https://starter.uppercut-labs.com/examples/agent-ready-website/) for Level 1
- [Command lesson](https://starter.uppercut-labs.com/phases/3/agent-cli.md) and [HTTP API lesson](https://starter.uppercut-labs.com/phases/3/agent-api.md) for Level 2, with the [example command archive](https://starter.uppercut-labs.com/examples/lantern-tools/lantern-tools-0.1.0.tgz) and the example API's [OpenAPI document](https://starter.uppercut-labs.com/examples/lantern-tools/v1/openapi.json)
- [MCP workshop and read-only example server](https://starter.uppercut-labs.com/examples/mcp-tool-library/README.md) for Level 3
- [Agent Native 1.1.0 example](https://starter.uppercut-labs.com/artifacts/agent-native-example/README.md) for Level 4
