# Quick Build artifact templates

Version: 0.1.0. Use these when the [Quick Build skill](https://starter.devthomas.site/skills/quick-build/current/SKILL.md) reaches planning. Replace bracketed fields with the learner's decisions. Adapt filenames to the repository's conventions. These are public blank templates, not this site's internal planning.

- [PLAN.md](https://starter.devthomas.site/artifacts/quick-build/PLAN.md): goal, scope, delivery sequence, and approval.
- [SPEC.md](https://starter.devthomas.site/artifacts/quick-build/SPEC.md): observable product behavior and completion.
- [DECISIONS.md](https://starter.devthomas.site/artifacts/quick-build/DECISIONS.md): durable choices and the reasons behind them.
- [TICKET.md](https://starter.devthomas.site/artifacts/quick-build/TICKET.md): copy into ordered files in `tickets/`.

Keep project-specific confidential plans in private storage. Show the learner a concise plain-English plan and wait for approval before implementation. The learner can inspect these files without needing to study their formats first.
