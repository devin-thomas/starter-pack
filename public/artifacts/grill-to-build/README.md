# Grill to Build artifact templates

Version: 0.2.0. Use these when the [Grill to Build skill](https://starter.uppercut-labs.com/skills/grill-to-build/current/SKILL.md) plans a Phase 2 project, after its canonical prerequisites pass, together with the [Phase 2 planning reference](https://starter.uppercut-labs.com/phases/2/planning.md). Make them available before the first question round. Replace bracketed fields with the learner's decisions. Reuse equivalent files the project already has. These are public blank templates, not this site's internal planning.

- [PROJECT.md](https://starter.uppercut-labs.com/artifacts/grill-to-build/PROJECT.md): the living project brief, scope, agreed rules, discovery progress and open questions.
- [GLOSSARY.md](https://starter.uppercut-labs.com/artifacts/grill-to-build/GLOSSARY.md): the project's own words for its things, created once the first term is settled.
- [ADR.md](https://starter.uppercut-labs.com/artifacts/grill-to-build/ADR.md): consequential decisions and the reasons behind them, appended rather than rewritten.
- [Ideas.md](https://starter.uppercut-labs.com/artifacts/grill-to-build/Ideas.md): good ideas deliberately left out of this build.
- [SPEC.md](https://starter.uppercut-labs.com/artifacts/grill-to-build/SPEC.md): observable behavior and acceptance, written after discovery settles.
- [TICKET.md](https://starter.uppercut-labs.com/artifacts/grill-to-build/TICKET.md): copy into ordered files in `tickets/`, written after the specification settles.

Keep confidential plans in private storage. The learner can read these files without studying their formats first. Show a concise plain-English summary and wait for an explicit go-ahead before implementation. Record build checks, availability, layout, and real-device behavior separately; unperformed human checks stay pending. On delivery use the [progress guide](https://starter.uppercut-labs.com/artifacts/progress/README.md) for revision-aware closeout and the final private save; these templates are not a second graduation registry.
